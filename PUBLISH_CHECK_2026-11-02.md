# Проверка публикации 2.0.1

В публикацию включён весь исходный проект: Android, PC-Bridge, тесты,
документация, исходные ресурсы и скриншоты проверки. APK публикуется релизом.

Проверено локально:
- 75 Android unit tests, без ошибок.
- 42 Node tests, без ошибок.
- `lintDebug` и `assembleDebug` выполнены успешно.
- Статический premium audit в strict-режиме: 0 findings.
- APK установлен на emulator-5554 с сохранением данных.
- Архив APK не содержит `pc_sessions_snapshot.json`.
- Удалённый main совпадал с исходным локальным HEAD перед публикацией.

Личные настройки OpenRouter, sync-state, логи, ключи подписи, node_modules и
результаты сборки исключены из Git. Слепок 212 ПК-сессий перенесён в локальную
игнорируемую `.private/`; Android source set дополнительно исключает его из APK.
Локальный поиск типичных credential-шаблонов обнаружил только resources.arsc.bin
из ChatGPT: SHA-256 этого файла совпадает с распакованным оригинальным APK.
Это ресурс исходного референса, не пользовательская настройка API.
Дополнительно GitHub push protection обнаружил Mapbox-токен в исходном
mapbox.js; строка токена заменена на REDACTED_MAPBOX_TOKEN до публикации.

В эмуляторе выполнены правка VERSION_CHECK → VERSION_CHECK_EDITED и переходы
2 / 2 → 1 / 2 → 2 / 2; соответствующий текст восстанавливается. Снимок:
verification_screenshots/chat_versions_restored.png. Использован ответ об
отсутствующем API-ключе, без платного вызова модели.

Версии сообщений проверены на сохранение ответов и вложений, вложенные правки,
переключение, недопустимые операции, локальную сериализацию, разделение backend
контекстов и защиту от перезаписи плоской серверной историей. Очередь сохраняет
принадлежность версии при перезапуске и смене серверного идентификатора.

Инференс с реальным ключом на телефоне в этом прогоне не выполнялся: ключей в
эмуляторе нет. Точные ограничения и доказательства по референсам перечислены в
RELEASE_NOTES_2.0.1.md и документах сравнения. Производственный мост не перезапускался.
