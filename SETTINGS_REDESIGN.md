# Переработка настроек

Было: длинная форма «Настройки и Голос», ключ Gemini внутри голосовой карточки,
технические пояснения и безусловное утверждение об активной синхронизации.

Стало: главный список → отдельные страницы аккаунта, голоса, моделей и ключей,
подключения к ПК, помощника Android. Разрешения открывают существующую панель.
Сохранены текущие обработчики, проверка микрофона и ключа, выбор голосов,
перебивание, адрес моста, публичный туннель и переходы в системные настройки.
Ключ скрыт по умолчанию, неверный/непроверенный ключ не получает старый результат
проверки. Версия приложения берётся из BuildConfig.

Основание: локальные референсы и ресурсы ChatGPT, существующий контракт проекта.
В refs_0.jpg видна структура сгруппированных строк экрана хранилища ChatGPT;
это частичный визуальный ориентир, не полный экран настроек. Исторические снимки
проекта r7b_step2_settings.png и r7b_step3_settings.png — свидетельство старого
экрана, не оригиналы ChatGPT/Claude. Настройки Claude вживую в этом проходе
не открыты: браузерный инструмент завершился тайм-аутом. Точное совпадение
с настройками Claude не заявляется. Функции, отсутствующие в референсах,
организованы средствами существующего Android/Compose интерфейса проекта.

Проверки: 77 модульных тестов прошли; strict UI audit — 0 замечаний.
Предварительный APK установлен в emulator-5554. Полный визуальный проход
не завершён: поверх приложения появлялись системные ANR Pixel Launcher и
System UI. Проверка реальных экранов на физическом устройстве и при увеличенном
шрифте остаётся открытой. Переключатель перебивания теперь читает/записывает
barge_in_enabled в существующих SharedPreferences.
