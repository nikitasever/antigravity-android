# Завершение и сохранение действий — 5 ноября 2026

Продолжение проверки субагентов. Внешний вид чата, сводки и списка задач сохранён.
Визуальное основание остаётся прежним: события Claude Remote control раскрываются
в переписке, результат выполнения отделён от основного ответа. Этот проход
исправляет достоверность этих статусов и результатов, а не копирует серверную
архитектуру референсов.

## Подтверждённые дефекты

1. В catch ошибки генерации выключался isStreaming, но события RUNNING могли
   остаться незавершёнными. При Stop менялся только RUNNING, а разрешённые и
   ожидающие разрешения действия могли продолжать выглядеть активными.
   Голосовое прерывание вообще не завершало события инструментов.
2. ChatSessionStore сохранял details без явного unifiedDiff. При восстановлении
   конструктор ToolCallEvent использовал details как diff по умолчанию: обычный
   файловый вывод превращался в блок изменений. Терялись также requiresApproval,
   approvalDecision и отдельное название инструмента.
3. После перезапуска нормализовался только RUNNING. APPROVED и AWAITING_APPROVAL
   оставались незавершёнными, хотя старый исполнитель больше не существует.
4. Секундный ограничитель persistStreamingChat мог пропустить начальный снимок
   задачи сразу после сохранения рассуждений. Пока ребёнок ожидает модель, новых
   сохраняемых событий может не быть: закрытие приложения теряет начало задачи.
5. Сетевая ошибка заявляла «мост ПК недоступен — запрос не отправлен» даже после
   частичного ответа или при работе с API. Теперь сообщение не делает такого
   ложного утверждения.

## Изменения

ToolCallLifecycle определяет незавершённые состояния и общее завершение с причиной.
Ошибка/восстановление даёт FAILED, Stop/голосовое прерывание — CANCELLED. Завершённые
действия, реальные diff и уже полученный вывод сохраняются. Ожидавшие разрешения
после восстановления становятся прерванными; автоматического запуска нет.

ChatSessionStore явно сериализует diff (включая null), название и метаданные
разрешений. Для старых записей без поля diff обычный вывод больше не интерпретируется
как изменения. Изменения списка инструментов обходят секундный ограничитель;
неизменные снимки на каждом текстовом токене не вызывают принудительную запись.

## Границы проверки

Модель в эмуляторном QA подменяется локальной детерминированной фикстурой;
сохранение, публикация событий и восстановление исполняются приложением Android.
Проверка голосового прерывания через реальный микрофон в этот проход не входит.
Прерывание сетевой ошибкой и состояния разрешений проверены модульными тестами
общей функции, а не полным прогоном каждого внешнего провайдера. Восстановление
после закрытия приложения проверено в настоящем Android-процессе.
