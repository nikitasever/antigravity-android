# Субагенты: что проверить и исправить

Дата: 2026-11-01.
Статус: план повторной проверки; пункты ниже ещё не означают выполненные исправления.

## 1. Причина пересмотра

Задача пользователя — опираться на ChatGPT и Claude, перенести подтверждённые
пользовательские сценарии и удобно реализовать собственные дополнительные функции.
Вместо проверки сценария делегирования была добавлена самостоятельная панель
«Субагенты» с полем задания и двумя кнопками запуска. Такой интерфейс по оригиналам
не подтверждён. Его нельзя называть переносом из ChatGPT или Claude.

Также не подтверждены обязательная пара «исследователь/рецензент», ручной запуск
этой пары и выдача двух отдельных отчётов как конечный сценарий оригиналов.
Работоспособность созданного исполнителя не доказывает соответствие референсам.

Предположение «делегирование должно быть внутри разговора» тоже нужно проверить:
это направление исследования, а не установленное описание обоих приложений.

| Частично разобранный класс Claude c2h0, методы p/q/u | В доступных участках формируются подписи участников | Серверную оркестрацию; JADX сообщил 9 ошибок |

| Оригинальный ChatGPT запускался в гостевом режиме | Проверены обычный запрос, ответ и ряд кнопок ответа | Полный сценарий делегирования, фоновых задач или работы с кодом |
| Наши тесты процессов и Git-копий проходят | Собственный исполнитель выполняет проверенные операции | Что оригиналы используют такую архитектуру или интерфейс |

Отсутствие понятного имени класса в обфусцированном DEX не доказывает отсутствие
функции. APK клиента не раскрывает автоматически серверную реализацию.
ChatGPT, Claude, Claude Code и Codex нельзя смешивать в один продукт: для каждого
наблюдения фиксировать конкретный клиент, экран и режим работы.

## 8. Текущие ограничения проверки

- Полный сценарий делегирования в оригиналах пока не установлен.
- Новый серверный код не подтверждён сквозным прогоном через работающий production-мост. Ранее автоматическая проверка отклонила его перезапуск с причиной `blocked by policy`; повторного перезапуска в рамках этого документа не выполнялось.
- Один живой CLI-тест подготовки файла прошёл в отдельном тестовом репозитории; это не проверка поведения ChatGPT/Claude.
- На эмуляторе наблюдался стартовый ANR «Application does not have a focused window». Повторный запуск прошёл; причину нужно установить отдельно.

Рекомендуемый порядок: доказательства оригиналов → исправление описания сценария →
переработка UI и связи с разговором → проверка жизненного цикла → полноценный
сквозной прогон. Применение изменений кода не должно отвлекать от исправления
основной ошибки: неподтверждённый интерфейс был принят за перенос референсов.
