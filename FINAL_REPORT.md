## 2. Реализовано «как у них»

### 2.1 Расширения, MCP и навыки
- **Поштучные права инструментов MCP** (их `McpToolPermission`/
  `McpSetAllToolsPermission`): allow/ask/deny, приоритет tool > «все
  инструменты сервера» > политика; проверка ДО соединения с честными отказами
  (`tool_denied`/`tool_needs_approval`); `userInitiated` пропускает ask.
- **Скоупы прав** (их «Always allow for this project / session / task /
  website»): приоритет task > session > tool > website > server > policy;
  session/task — память моста (не переживают перезапуск — честно), website —
  только HTTP-origin (stdio — отказ `website_scope_requires_origin`).
- **Deny with comment**: комментарий к запрету сохраняется с правом, попадает
  в текст отказа модели («Комментарий пользователя: «…»») и в UI («💬 …»);
  повторный deny без комментария очищает прежний.
- **Режимы разрешений** (их enum `PermissionMode` = default/plan/auto/
  acceptEdits/dontAsk/bypassPermissions — разобран по декомпиляции):
  API `permission_mode`/`set_permission_mode`, enforcement в callTool;
  «deny прав никогда не обходится».
- **SkillEdit** (их `SkillEdit` + «Skill name» + «Delete skill?»): редактор
  SKILL.md, переименование со стабильным id и отказом дубликата имени
  (`skill_name_taken`), встроенные навыки — только чтение
  (`skill_read_only`), удаление с подтверждением «Навык и его история версий
  будут удалены навсегда.».
- **Деталь навыка** (их `ViewSkillInstructions`/`SkillDetail`) — полный текст
  SKILL.md; **деталь карточки каталога** (их `ConnectorDirectoryDetail`) —
  паспорт позиции (издатель/источник/сценарий, честные «не записано»).

### 2.2 Субагенты и фоновые задачи
- Панель «как у них» (их «%1$d running task(s)»/«No background tasks»/«Your
  computer is busy…»): счётчик с русскими склонениями («2 задачи выполняются»),
  «Нет фоновых задач», busy-строка (скрыта для своей пачки — «другими
  сессиями» было бы неверно), подсказки shared/isolated рабочего каталога.
- Уведомления с действиями (их notification-воркеры → наши «Отменить»/«Открыть»):
  «Выполняются 2 задачи…» + «Отменить» (действие реально отменяет пачку),
  «Задачи завершены [с ошибками]» + «Открыть», «Задачи отменены. Отменено: N.»;
  POST_NOTIFICATIONS — soft (без разрешения тихий no-op).

### 2.3 Композитор и чат
- **@-токены** (их `ComposerPlugin{TokenType/Trigger/TokenActionType}`):
  фишки упоминаний над вводом (INSERTED/REMOVED, дубликаты не добавляются),
  «Упомянуть…» в меню «+» (их PLUS_MENU), ввод «@» (их TYPED_AT) прежний;
  токены добавляются к промпту перед черновиком.
- **Правка сообщения → версии разговора** (живая находка claude.ai web):
  реализовано ранее — `ChatMessageVersions.kt` (архивация хвоста в ветки
  версий, UI «Предыдущая/Следующая версия»); устаревший статус сверки
  исправлен.

### 2.4 Дизайн «схожий» (по артефактам, не по впечатлениям)
- Токены `app/src/main/java/com/google/antigravity/ui/design/DesignSystem.kt`:
  - **ChatGPT** (декодировано из декомпиляции, `qdm0.h(<decimal ARGB>)`):
    нейтрали `#0D0D0D` (фон), `#212121`/`#303030`/`#414141`, текст
    `#F3F3F3`/`#C4C3CB`/`#89888D`, акценты `#3566F0`, `#04BB9F`, `#FFCC38`,
    `#FF8066` и др.; шрифты OpenAI Sans + Söhne (в APK).
  - **Claude** (res/values/colors.xml): тёплая бумага `#FAF9F5`/`#E7E6E1`,
    коралл `#D97757`/`#C6613F`, шалфей `#7FA87F`; шрифты Google Sans.
- Листы прав/навыков и панели субагентов приведены к этим токенам (кегли
  18/14/14/12/11, радиусы карточек 12dp, акцент `#3566F0`).

## 5. Честные границы (не выдаётся за реализованное)

- Их Auto-режим (модельная оценка рисков и prompt injection) и их семантика
  скоупов/комментария к запрету — **не воспроизводятся**, наши модели
  заявлены в UI как «по мотивам» («требует проверки»).
- Шрифты референсов (Google Sans, OpenAI Sans, Söhne) не
  перераспространяются — в комплект не включены; типографика приближена
  кеглями/весами системного шрифта.
- Error-red ChatGPT не декодирован — используется их коралл `#FF8066`.
- baton-переписка, категории Teammates/Other sessions, MCP Apps — отложено
  (нет сессионной модели/продуктового движка; решение от 1 ноября «не
  выдавать за воспроизведение» в силе).
- Декомпиляция обоих APK — частичная (61%/55%, память JVM); extension-пакеты
  проверены поимённо.
- Тёмная база Antigravity сохранена; светлые темы референсов существуют
  (`#FFFFFF`/`#FAF9F5`-семейства) — возможная отдельная волна.
