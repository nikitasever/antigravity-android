# Исправление компоновки после визуального отклонения

Предыдущая сборка прошла автоматические проверки, но это не подтвердило её
визуального соответствия. Пользователь отклонил результат. Этот проход меняет
компоновку, а не только палитру.

## Использованные оригинальные экраны

- ChatGPT: `reference-live-2026-11-04/Screenshot_20261104_091531_ChatGPT.jpg` —
  плотность шапки, три основных элемента, сегменты и нижняя пилюля.
- Claude: `reference-live-2026-11-04/Screenshot_20261104_090914_Claude.jpg` —
  иерархия настроек, карточка профиля, группировка и строки с иконками.
- Claude: `reference-live-2026-11-04/Screenshot_20261104_090907_Claude.jpg` —
  wordmark и нижняя белая кнопка нового чата.
- Предоставленные пользователем Claude Code Remote control — меню действий
  беседы и сохранение инструментов внутри разговора.

## Изменения

1. `ConversationHeader` заменяет двухъярусную шапку: 48dp, адаптивные сегменты,
   модель/контекст/поиск/содержание в меню. Три основных элемента вместо четырёх
   кнопок и отдельной строки технической информации. Справа меню, а не точная
   копия кнопки временного чата ChatGPT: это явный вариант объединённого продукта.
2. Пустой чат не содержит придуманного двухстрочного приветствия.
   Общая геометрия `ChatModeHeader` используется также во вкладке «Работа»;
   переключение вкладок не возвращает прежние размеры и отступы шапки.
3. Композер: #303030, обводка 1dp, радиус 32dp, увеличенные плюс/микрофон,
   короткая подсказка без справки о командах. Черновики, очередь, файлы, отправка,
   Stop и голос сохраняют существующих владельцев и обработчики.
4. Drawer: крупный serif-wordmark, крупнее пункты, белый «Новый чат» снизу.
   Исправлено двойное сужение ширины; поиск больше не переносит placeholder
   на две строки. Архив, поиск по содержимому, контекстные действия и инструменты
   телефона/ПК сохраняются.
5. Настройки: serif-заголовок, карточка профиля, группы строк с иконками без
   постоянных технических пояснений. Поиск открывается кнопкой шапки. Вложенные
   настройки и реальные действия не заменены макетами.
6. Экран входа: удалены придуманная орбитальная анимация и «AI Pro» у входа
   через ПК. Спокойный текстовый экран сохраняет прежние способы входа.
   Это адаптация, не утверждение о буквальном совпадении с экраном входа референса.
7. При визуальной проверке свежая установка показала захардкоженную почту как
   профиль Google. Удалены значения по умолчанию `user_name`/`user_email` из
   ViewModel; сохранённые пользовательские значения не очищаются. Отображение
   профиля само по себе не доказывает OAuth-авторизацию.

## Проверка

Создан отдельный AVD `Codex_Reference_UI` на имеющемся Android 37. Исходный
`Pixel_8a` не сбрасывался. Новый AVD загрузился; установлен и запущен APK с новой
шапкой, композером, настройками и drawer. Сняты и просмотрены реальные кадры
`uploads/reference-after-chat.png`, `uploads/reference-after-drawer.png`,
`uploads/reference-after-settings.png`. При первом старте были системные ANR
Launcher/System UI; они не выдаются за дефекты приложения или успешные проверки.

Кадры выявили длинную подсказку, двойное сужение drawer и подставной email;
внесены дополнительные исправления. Промежуточная сборка `assembleDebug` и
`testDebugUnitTest` успешна (10 мин 33 с). Окончательная проверка последних
исправлений и повторное снятие кадров фиксируются отдельно после сборки.

Нет заявления о полном пиксельном совпадении, проверке всех экранов, работе
платных облачных функций или проверенном live-голосе. Системный serif не является
лицензионным шрифтом Claude.
