# Проверка открытой веб-версии Claude

Дата: 2026-11-01. Проверена предоставленная пользователем авторизованная вкладка
claude.ai в Chrome внутри emulator-5554. Это живой веб-референс, не Android APK.
Аккаунт показывает Free. Наблюдаемая подпись выбранной модели: Haiku 5.5 Medium.
Интерфейс отображался с широкой боковой навигацией; мобильную раскладку этим
прогоном не считаем проверенной. Приватные API, cookies и токены не извлекались.

REA list_browser_targets вернул invalid_endpoint_response. Продолжение выполнено
обычным CDP через ADB-forward к мобильному Chrome: Accessibility, DOM.getBoxModel,
Input и Page.captureScreenshot. Эти результаты не являются REA Evidence.

## Что это означает для нашего проекта

### Подтверждённое расхождение: редактирование и версии разговора

`AntigravityViewModel.editAndResendUserMessage` сохраняет исходную сессию,
затем назначает новый activeConversationId и отправляет исправленный запрос.
Это отдельный чат, тогда как в наблюдаемом Claude версии выбираются внутри
того же разговора. Наш отдельный branchFromMessage также не заменяет этот сценарий.

Нужен перенос модели версий:

1. Хранить альтернативы пользовательского хода и соответствующие продолжения,
   а также выбранную ветку, внутри одной идентичности разговора.
2. Edit/Save создавать новую альтернативу, сохраняя исходную. Cancel не меняет историю.
3. Показывать переключатель версий рядом с изменённым сообщением.
4. При переключении менять видимое продолжение и контекст следующего запроса
   без повторной генерации старого ответа.
5. Сохранять ветки и выбор на телефоне, учитывать их в синхронизации и временном
   режиме. Миграция плоской истории не должна удалять существующие чаты.
6. Проверить вложения, прерванную генерацию, повтор ответа и возврат после перезапуска.

Это задача переноса по наблюдению. В данном проходе модель хранения и UI проекта
не изменялись: сначала зафиксировано воспроизводимое отличие.

### Субагенты: что остаётся неизвестным

В проверенных меню обычного чата отдельной формы запуска субагентов не было.
Это не доказательство отсутствия такой функции во всех режимах Claude.
Code в предоставленном аккаунте открыл тарифы, поэтому создание субагентов,
их статусы, делегирование ведущей моделью и объединение результатов не наблюдались.
Статический Android BackgroundTasksDetail относится к CodeRemote и не может
заполнить этот пробел без проверки переходов и источника событий.

Наши кнопки ручного запуска и обязательная пара исполнителей остаются собственным
сценарием, а не подтверждённым переносом. Их нельзя развивать под видом эталона.
Для изменения основного потока нужно отдельно решить судьбу дополнительной
функции проекта и сверить доступный режим работы с кодом.

## Границы результата

Проверены обычный разговор, меню инструментов, начало генерации, отмена редактора,
сохранение правки и реальное переключение двух версий. Не проверены полный цикл
субагентов, остановка генерации нажатием Stop, длительные фоновые задачи, offline,
инкогнито, публикация/экспорт и поведение нативного Android-клиента после входа.
Веб-наблюдения не выдаются за восстановленный серверный код или за совпадение APK.
