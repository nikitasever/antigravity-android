# Перенос функциональности ChatGPT + Claude

Продуктовое решение пользователя: одно приложение между двумя локальными APK.
Существующий Android/PC функционал встроить в единую навигацию. Источники:
REFERENCE_EVIDENCE.md. Строки и имена классов подтверждают наличие возможностей,
но не заменяют контракт закрытых облачных API.

| Сценарий | Источник | Реализация проекта / фактическая граница |
|---|---|---|
| Чат, вложения, отправка/стоп | ChatGPT screenshot composer + strings | Compose composer; отмена HTTP/удалённого turn; сохранение вложений |
| Редактирование и повтор | ChatGPT Edit message; Claude Edit and retry | ChatHistoryPolicy, новая ветка с сохранением предыдущих сообщений |
| История, поиск | ChatGPT drawer screenshot; Claude search resources | Поиск по названию, сохранённым сообщениям и именам вложений |
| Закрепление | ChatGPT Pin/Unpin chat strings | ChatLibraryPreferences, устойчиво к обновлению списка с ПК; синхронизируется с мостом через /api/sync/state |
| Переименование | Оба APK; декомпилированный Claude Rename | Диалог названия, сохранение на устройстве и синхронизация с ПК; серверное имя сессии не изменяется |
| Архив | Оба APK Archive strings | Локальный архив с синхронизацией, отдельный фильтр и восстановление; без удаления |
| Содержание разговора | Claude ConversationOutline destination | Sheet со всеми запросами пользователя и переходом к сообщению |
| Поиск в открытом чате | Развитие общего поискового сценария | Совпадения в сообщениях и вложениях, предыдущий/следующий переход |
| Длинные ответы | Чатовый сценарий обоих APK | Раздельное следование за потоком и ручное чтение, кнопка возврата вниз |
| Размышления | ChatGPT Expand/Collapse reasoning; Claude ViewThinking | Отображаются только полученные данные, ручное раскрытие сохраняется |
| Действия сообщения | ChatGPT/Claude Copy, Retry и др. | Копирование, выделение, правка, повтор, share и озвучка |
| Код и отдельное чтение | Claude ArtifactFullScreen; ChatGPT code blocks | CodeArtifactViewer: выделение, копирование, перенос строк, сохранение |
| Библиотека / проекты | Оба APK gallery/project destinations | Реальные проекты ПК; инструкции проекта, документы контекста и связанные чаты локальной рабочей области ProjectWorkspace; библиотека сохранённых ответов с редактированием, версиями, интерактивным HTML-предпросмотром, поиском, Markdown-экспортом, удалением и синхронизацией с ПК; облачная память проектов не перенесена |
| Временный чат | ChatGPT «Временный чат» (ru-строки #3573) | Эфемерные переписки: не сохраняются на телефоне и ПК (transient-флаг → без транскрипта), без контекста проектов и памяти; индикатор в чате |
| Голос и диктовка | Оба APK voice services | Существующий VoiceEngine, TTS/Live, разрешения и отмена; реальная проверка микрофона с уровнями, barge-in с отменой генерации, диктовка с честными ошибками и переподключение живого WebSocket с backoff; отдельный живой микрофонный прогон ещё не выполнен |
| Работа / окружения | ChatGPT Codex screenshot; Claude remote destinations | Существующие PC-сессии и фильтры окружений сохранены |
| Телефон / CLI / MCP / права | Собственная функциональность | Все прежние входы сохранены в раскрываемом разделе «Инструменты» |
| Облачные аккаунты / подписки | Закрытые серверные интеграции оригиналов | Не эмулируются; извлечение APK не предоставляет авторизацию или серверный код |
| Публикация/исполнение артефактов | Claude artifact resources | Полноэкранный просмотр исходника реализован; облачная публикация не заявляется |
| Медиа, Drive, compact | Зависит от настоящих серверов | Реальные интеграции: генерация изображений через OpenRouter API (без ключа — честная ошибка; видео недоступно), сжатие контекста реальной моделью с сохранением локальной истории, Google Drive REST v3 с OAuth и обновлением токенов; без учётных данных — честный отказ, заглушек нет |

Это карта фактического состояния переноса, а не заявление о полном клонировании
оригиналов. Модели, аккаунты и серверы оригиналов не становятся доступными
от копирования их APK, native SO или ресурсов.
