# Проверка 2.1.1

## Исправления после 44bc714

1. Предыдущая интерполяция имела минимальный шаг на кадр: при высоком FPS
   переход ускорялся. `VoiceOrbMotion` использует фактическое время и кривую
   `atan(4 * sin((progress - 0.5) * PI)) / atan(4) / 2 + 0.5` из
   `perdex-out/chatgpt-classes4/sources/zr31.java`, обычная длительность 0.65 с.
   Переназначение цели при перебивании продолжает текущую форму. Привязка статусов
   проекта к четырём каналам — наша адаптация; полный контроллер оригинала не заявлен.
2. Старая временная шкала и cumulativeAudio переживали onSurfaceCreated, хотя
   shader time начинался заново. Теперь они сбрасываются вместе. Инициализация
   новой поверхности отделена от ошибки рендера: Canvas виден до нового кадра.
   Таймаут GPU действует только при RESUMED: пребывание в фоне во время прогрева
   больше не засчитывается как ошибка и не отключает шейдер до конца разговора.
3. Добавлены JVM-проверки одинаковой скорости при разных FPS, перебивания без
   скачка, сброса времени и стабильности timestamp между состояниями слушания.
4. Дополнительный снимок после возврата выявил смешение координат разных окон
   Dialog/Activity. Измерения теперь используют positionOnScreen, игнорируют
   ещё не размещённую панель, а квадрат сферы ограничен доступными шириной и высотой.

## Публикация

Версия 2.1.1, versionCode 20261107. Изменение `.github/release.json` запрашивает
публикацию через существующий build workflow только после тестов, lint и сборки.
Версия сверяется с Gradle; существующий тег другого коммита запрещён. Обычные
последующие коммиты без изменения запроса не создают и не перезаписывают Release.
GitHub публикует Debug APK и SHA256SUMS.txt; это явно указано в release notes.
Локальная подписанная release-сборка проверяется отдельно и не выдаётся за CI APK.
Закрытый ключ и keystore.properties в GitHub не передаются.
