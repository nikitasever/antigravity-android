## 3. Декомпиляция (per-dex, JADX 1.5.6)

### Метод
- Каждый `classesN.dex` декомпилирован **отдельным** прогоном jadx (`-r -j 2 --rename-flags none`, heap 3 ГБ) — обход предыдущего обрыва по памяти JVM (61%/55% при прогоне всего APK).
- Claude: 5 dex (54 940 class_defs); ChatGPT: 9 dex (83 704 class_defs). Итого 138 644 class_defs.
- Эталонные списки классов извлечены парсером DEX (`dex_class_list.py`): `classlists/*.txt`.
- Покрытие проверено верификатором (`verify_coverage.py` + `verify_union.py`): для каждого имени class_def ищется свой .java (inner-классы — внутри файла внешнего или отдельным файлом).

### Природа пропусков (честная квалификация)
- **~7 200** — R8-обфусцированные классы (однобуквенные имена `a660`, `phn0`, …): часть не сохранена jadx при ошибках декомпиляции («finished with errors, count: 343» на dex), часть помечена `DONT_GENERATE` (синтетические CREATOR и т.п. — jadx пишет их внутрь файлов под другими именами).
- **~185** — библиотечные (androidx, j$.time и др.); многие фактически присутствуют в старых выводах full-claude/full-chatgpt.
- **~56** — прикладные классы `com.openai.*`/`com.anthropic.*`; для них выполнен точечный `--single-class` gap-fill (49 запусков), дополнительно сохранены `ChatGptDeeplinkActivity`, `PurchaseResult$Error` и др.; часть (например `com.openai.feature.artifactlibrary.impl.a`) jadx отказывается сохранять (`DONT_GENERATE`) — эти классы синтетические.
- Полные списки пропусков: `coverage-reports/UNION_missing.txt` и `coverage-reports/*.coverage.txt`.
