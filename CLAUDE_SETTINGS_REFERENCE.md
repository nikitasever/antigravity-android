# Claude: живая сверка настроек

Дата: 2 ноября 2026. Источник: открытая пользователем вкладка Edge,
https://claude.ai/new. Чат сообщает Organization disabled, но меню настроек
открывается и позволяет просматривать разделы. Настройки аккаунта не изменялись;
сообщения, экспорт, удаление, смена разрешений и обход блокировки не выполнялись.
Персональные данные аккаунта и история чатов в этот отчёт не включены.

## Подтверждено в интерфейсе

- Настройки открываются из меню профиля; самостоятельное окно с постоянной
  навигацией по разделам и поиском сверху.
- Разделы: Account, Billing, Appearance, Your Claude, Capabilities,
  Notifications, Privacy, Wellbeing, Customize, Code. API keys — отдельная ссылка.
- Appearance: тема System/Light/Dark, шрифт интерфейса, шрифт ответа,
  размер текста разговора, ширина разговора, анимация. Компактные строки,
  подпись слева, выбранное значение справа, тонкие разделители.
- Capabilities: артефакты, диаграммы, создание файлов; отдельная секция Voice
  с языком, стилем и скоростью. Подпись и пояснение слева, переключатель справа.
- Your Claude: инструкции отдельно от памяти; управление, импорт и экспорт памяти
  представлены отдельными действиями. Их исполнение не проверялось.
- Privacy: настройки использования данных отдельно от управления данными.
  Экспорт, общие чаты, артефакты, вложения, обратная связь и память — отдельные
  строки. Удаление серверных Claude Code сессий явно отличает их от локальных.
- Code на данном аккаунте предлагает платный план. Создание субагентов здесь
  не наблюдалось; по этому экрану делать вывод о его устройстве нельзя.
- Поиск: ввод `voice` дал Capabilities → Voice; выбор результата открыл
  capabilities. Поиск ищет также внутри разделов, а не только их названия.

## Адаптация к Android-проекту

Главный сгруппированный список и вложенные страницы из 2.0.3 остаются подходящей
адаптацией для телефона. В AppSettingsScreen добавлен поиск существующих разделов
и их параметров, переход к найденному разделу, очистка и пустой результат.
Никаких сетевых запросов и поиска по секретным значениям он не делает.

Тема, шрифты, память, обучение, платёжные настройки и скорость голоса из Claude
не добавляются фиктивными переключателями: соответствующие механизмы проекта
нужно реализовывать и проверять отдельно. Устройство веб-настроек Claude не
приравнивается к интерфейсу его Android APK.
