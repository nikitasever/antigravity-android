## Обязательные визуальные сценарии

1. Узкий экран и крупный системный шрифт: короткие CODE-токены целиком,
   длинный Windows-путь внутри чипа, без потери символов и горизонтального обрезания.
2. Ссылка после чипа открывает исходный URL. Копирование сообщения/кода сохраняет
   исходный путь и версию без добавленных разделителей.
3. Длинная строка в fenced code переносится; diff сохраняет цвета; Copy/Save работают.
4. Ответ serif, пользователь sans; выбор SYSTEM переживает перезапуск приложения.
5. Шиты закрываются крестиком и Back; длинные заголовки не перекрывают крестик.
6. Настройки → профиль/уведомления; поиск; Back возвращает к корню. После изменения
   разрешения в Android статус уведомлений актуален.
