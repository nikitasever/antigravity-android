# Проверка запуска и отображения подзадач — 5 ноября 2026

## Основание

Проверены PhoneAgentEngine, телефонный маршрут AntigravityBackendClient,
привязка задач к разговору в AntigravityViewModel, ConversationActivity и
прежняя панель в Round5PanelsAndSheets. Визуальное основание — предоставленный
скриншот Claude Code Remote control IMG_20261101_232725_890.jpg: строка
Processing / running task над полем ввода и раскрываемые события в переписке.
Скриншот не показывает форму создания пары агентов. Локальные APK-находки и
границы их интерпретации изложены в SUBAGENTS_COMPARISON.md и
CLAUDE_REMOTE_CONTROL_REFERENCE.md. Серверный механизм Claude не восстановлен.

## Подтверждённые дефекты и изменения

1. Старая форма «исполнитель + рецензент» оставалась в коде, вопреки UX-CONTRACT.
   Удалена. BackgroundTaskSheet — единственный владелец списка и деталей задач;
   запускающего поля и кнопок «Запустить анализ / код-задачу» больше нет.
2. Индикатор включался только флагом legacy-пакета ПК. Автоматический delegate_task
   телефона не показывал его. Теперь основание — реальные незавершённые задачи,
   включая settling; обычные инструменты не увеличивают число субагентов.
3. Зелёная капсула с пиксельной сеткой и встроенная большая карточка заменены
   плоской строкой-ссылкой. Нажатие открывает один bottom sheet с общим SheetHeader,
   прокручиваемыми строками и отдельной кнопкой остановки при реальной работе.
4. Состояние занятости и запуска legacy-ПК было глобальным. Его публичное
   представление теперь ограничено исходным разговором. Счётчик объединённого
   списка считается по текущим задачам, а не по устаревшему remote snapshot.
5. Исчерпание трёх шагов дочернего исполнителя возвращало успешный delegate_task.
   Теперь это FAILED, а родитель получает наблюдение «delegate_task: ошибка».
6. В сводке действий delegate_task получает отдельный значок, инструменты ребёнка
   показаны с отступом; отклонённая рекурсивная попытка не создаёт новую строку
   самостоятельной задачи.
7. Добавлен пункт «Фоновые задачи» в меню чата: результаты доступны и после
   исчезновения индикатора выполнения. Переиспользуется тот же bottom sheet.

## Границы результата

Модельные ответы в QA заменяет локальный детерминированный HTTP-сервер; Android
оркестратор, публикация событий, файловый инструмент, отмена и сохранение остаются
настоящими. Этот прогон не доказывает качество делегирования коммерческой модели
и не подтверждает выполнение на физическом телефоне или настоящем CLI ПК.
Дочерние задачи телефона выполняются последовательно, не рекурсивно, максимум
две за ход, с тремя шагами и только инструментами чтения. Локальная оркестрация
не означает локальный inference: выбранной CLI-модели по-прежнему нужен ПК.
Удалённый legacy-пакет проверен модульными тестами, его реальное CLI-исполнение
и одновременная работа телефона/ПК не проверялись. Механизм создания субагентов
Claude/ChatGPT не выдаётся за восстановленный код этих сервисов.
