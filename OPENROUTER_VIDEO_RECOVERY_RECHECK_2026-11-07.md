# OpenRouter: восстановление ожидания видео в Android, 2026-11-07

Следующий проход: OPENROUTER_VIDEO_CONTROLS_RECHECK_2026-11-07.md подключает
остановку/продолжение в UI и исправляет карточку медиа. Ограничение о кнопках
ниже относится к состоянию до этого следующего прохода.

Этот проход продолжает OPENROUTER_VIDEO_RECHECK_2026-11-07.md. Добавлена
долговечная запись ожидания на телефоне до отправки платного запроса. При
восстановлении приложение запрашивает статус исходной задачи, не создаёт новую.

## Изменения

- VideoRunStore хранит requestId, исходные чат/мост/модель/промпт и SHA-256 ключа,
  если ключ был задан на телефоне. Сам ключ не записывается. Пустой хеш означает
  использование настроенного на исходном мосту ключа; новый телефонный ключ не
  подставляется в такой запрос. Токены в URL журнала запрещены.
- Запись атомарна, повреждение журнала блокирует его перезапись. Ограничение 32
  незавершённые записи не удаляет старые задачи ради новых.
- После перезапуска Android выполняет только status/download. При смене чата или
  адреса текущего моста результат сохраняется в исходный чат. Если снимок истории
  отсутствует, исходные сообщения восстанавливаются по стабильным ID журнала.
- Запись удаляется после сохранения файла на телефоне и подтверждённой записи
  истории. Подтверждённые failed/cancelled/expired завершают ожидание после записи
  ошибки. Неоднозначное состояние не запускает платную генерацию повторно.
- Временный чат не пишет такой журнал, историю или строку в списке чатов.
- Загрузка на телефон идёт во временный файл с проверкой размера, затем заменяет
  целевой файл. Оборванная загрузка не должна портить ранее сохранённый файл.

## Границы

Прямой запуск video API с телефона без PC-Bridge пока не реализован. Новые
Stop/Resume-действия в интерфейсе ожидания не подключены. Остановка наблюдения не
равна отмене оплаченной генерации у провайдера. Восстановление временных чатов
после завершения процесса намеренно не выполняется.

Контролируемый сервер использует искусственный 24-байтовый MP4-заголовок:
это проверка протокола и файлов, не генерация/проигрывание настоящего ролика.
Новых коммерческих вызовов OpenRouter в этом проходе не выполнялось. Предыдущие
живые проверки текста, каталога и отказа image API по балансу описаны отдельно.
