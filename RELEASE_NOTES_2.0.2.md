# Antigravity Android 2.0.2

Исправлен отказ CLI-моделей в режиме телефона. Gemini 4 Argon и Gemini 3.8
используют существующий телефонный маршрут PC-Bridge для модельного ответа;
PhoneAgentEngine продолжает выполнять телефонные действия на Android.
Выбранная модель не заменяется, ключ Gemini/OpenRouter для CLI не требуется.
Для CLI нужен подключённый ПК с Antigravity и работающий мост. API-модели
сохраняют прямое подключение без моста.

Каждый модельный шаг получает отдельный CLI-контекст, родитель получает текущую
видимую историю, дочерняя задача — только свой запрос. Файлы-вложения целиком
на ПК этим маршрутом не загружаются; используются текстовые превью.

Проверка существующего живого моста: POST /api/chat с mode PHONE_LOCAL_RESOURCES,
model gemini-4-argon-high, transient true вернул ok true и PHONE_CLI_OK от той же
модели. Производственный мост не перезапускался. APK остаётся debug-сборкой.
