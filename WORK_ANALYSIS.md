## 2. Выполненные блоки (список «до полного объединения»)

### 2.1 Проекты (раунд 1)
- `ProjectWorkspace` — локальная рабочая область: **инструкции проекта**, **документы
  контекста** (project knowledge), **связанные чаты** (один чат — один проект).
- Контекст (инструкции + документы) входит в запросы модели только для связанных
  чатов, включая голосовые; без него запрос не изменяется.
- UI: `ProjectWorkspaceScreen` — список + карточка (редактор инструкций, документы
  с системным выбором файла до 16 МБ, управление привязками чатов).
- Тесты: `ProjectWorkspaceTest` (6) — round-trip JSON, повреждённые данные,
  идемпотентность привязок.

### 2.2 Артефакты (раунд 2)
- **Редактирование**: заголовок и содержимое локальных сохранённых копий.
- **Версии**: не-разрушительная история до 20 снимков (правка, восстановление,
  повторное сохранение — снимок прежнего текста); восстановление сохраняет
  версию в истории.
- **Интерактивный предпросмотр**: переключатель «Предпросмотр/Исходник»,
  Markdown-рендеринг, HTML — интерактивный WebView (как preview артефактов
  оригиналов).
- Тесты: `ArtifactVersionsTest` (6).

### 2.3 Синхронизация с ПК (раунд 3)
- Новые маршруты моста `GET/POST /api/sync/state` (`sync-state.json`): названия,
  закрепления, архив чатов и библиотека сохранённых ответов.
- Детерминированное слияние «побеждает более новый `updatedAtMs`»; удаления —
  надгробиями; метка названия меняется только при изменении содержимого (открытие
  чата не перетирает переименование с другой стороны).
- Push после каждого локального изменения + при синхронизации сессий; принятие
  ответа без перетирания более новых локальных правок.
- Тесты: `ChatSyncMergeTest` (5) + `sync-state.test.js` (5) + усилен `drive-status.test.js`.

### 2.4 Голос (раунд 4)
- **Проверка микрофона**: реальная запись ~1.2 с с уровнями (пик/средний/сэмплы),
  различение «нет разрешения / тишина / работает».
- **Прерывания (barge-in)**: все пути (распознаватель, уровень PCM, касание сферы)
  сведены в `performBargeInInterrupt` — речь прерывает озвучку **и отменяет
  текущую генерацию**.
- **Диктовка**: предварительная проверка разрешения; фатальные ошибки распознавания
  честно останавливают диктовку (без бесконечного тихого повтора).
- **Восстановление соединения**: переподключение WebSocket с экспоненциальной
  паузой 1→2→4→8→16 с (далее 30 с), статус `RECONNECTING`, защита от устаревших
  сокетов поколением сессии.
- Тесты: `VoiceDiagnosticsTest` (5).

### 2.5 Серверные функции (раунд 5)
- **Генерация изображений**: реальный OpenRouter API (`modalities: image`), PNG с
  реальными размерами из IHDR; без ключа — честная ошибка. Видео — честный отказ
  (нет видео-моделей в OpenRouter через мост).
- **Сжатие контекста**: `/api/context/compact` вызывает реальную модель (тот же
  конвейер, что и чат); на телефоне `/compact` вставляет сводку разделителем —
  локальная история не удаляется, модель видит сводку + свежие сообщения.
- **Google Drive**: настоящий Drive REST API v3 с OAuth (Client ID/Secret,
  refresh-токен, автообновление, loopback-флоу `/api/gdrive/oauth/*`), прокси
  скачивания (токен не покидает ПК). Без OAuth — локальное зеркало с честным
  `connected: false`.
- Тесты: `server-functions.test.js` (3), `ChatHistoryPolicyTest` +2.
