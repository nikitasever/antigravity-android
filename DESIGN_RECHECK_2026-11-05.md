## Исправленные функциональные дефекты

1. Незавершённый fenced code при стриминге рендерился как проза до получения
   закрывающего fence. Теперь блок кода виден сразу. Закрытие распознаётся на
   отдельной строке, с поддержкой длинных fences, тильд и CRLF; backticks внутри
   строк программы не обрывают блок. Добавлены пять регрессионных JVM-тестов.
2. При переполнении очереди ViewModel возвращал текст только в StateFlow после
   очистки UI-черновика. Возвращённый текст теперь также сохраняется через
   существующий setComposerDraft с учётом временных чатов.
3. Переключатели версий выглядели доступными во время ответа: проверялся только
   isStreaming пользовательского сообщения. UI теперь использует состояние всей
   беседы; существующий защитный отказ модели данных сохранён.
4. Поиск не учитывал изменение набора совпадений при поступлении ответа.
   Эффект учитывает searchMatches; Back сначала закрывает поиск.
5. APPROVED-инструмент мог попадать в завершённую сводку; он теперь учитывается
   как незавершённое действие. Кнопки разрешения показываются только в статусе
   AWAITING_APPROVAL, а не у завершённых/отменённых записей со старым решением.
6. Промежуточная адаптация нового composer потеряла фокус при первом символе
   (эмулятор: вместо ABC осталось A). Перенос редактора между родителями удалён:
   теперь изменяются кнопки, сам редактор остаётся в одной позиции композиции.
   На исправленном APK получено ABC без повторного фокуса; после force-stop
   и запуска тот же черновик восстановился.
7. У синей кнопки голоса отсутствовало доступное название. Добавлена подпись
   «Начать голосовой разговор». Модель видна в нижней строке расширенного ввода
   и открывает существующий выбор модели, как в предоставленном Remote control.
8. В системной светлой теме Material3 1.3.0 выбирал тёмные значки для тёмного
   модального окна. Причина проверена в используемом material3-release.aar:
   ModalBottomSheet_androidKt вызывает isSystemInDarkTheme, а DialogWrapper
   инвертирует результат для WindowInsetsController. FixedDarkAppearance согласует
   Compose-конфигурацию с фиксированной тёмной темой приложения, сохраняя fontScale,
   density и locale. Устройство не переключается в другую системную тему.
   У Activity и обоих native themes также заданы светлые значки системных панелей.
9. При восстановленной очереди из 10 сообщений и открытой клавиатуре редактор
   исчезал из доступного дерева: вся высота уходила на строки очереди. Воспроизведено
   на APK (uploads/design-queue-cap-before.png и .xml). Список теперь ограничен
   96 dp с собственной прокруткой, число сообщений видно отдельно; редактор и
   управление генерацией находятся за пределами прокрутки очереди.
