---
name: workspace-check
description: Проверить состояние Git и незавершённые конфликты перед правками проекта.
license: MIT
---
Запусти `node scripts/check.js --workspace <абсолютный путь проекта>` из каталога
этого навыка. Скрипт только читает Git status и diff --check; не меняет файлы,
не делает commit, reset, clean или push. Покажи dirty-файлы и ошибки проверки.
Не выдавай этот результат за сборку или тесты проекта. Перед правками сохрани
чужие изменения; hooks — дополнительная проверка, не изоляция shell-команд.
