# Продолжение сверки: вложения и выбор модели

## Что изменено

- ChatAttachmentSheet заменяет три крупные плитки вертикальным списком действий.
  Основание — живой ChatGPT Android, Screenshot_20261104_091526_ChatGPT.jpg:
  панель с боковыми отступами, нейтральные круги значков, строки камера/фото/файлы/
  плагины. Дополнительные действия приложения отделены разделителем.
- Сохранены прежние Android launcher-контракты камеры, фото и файлов, добавление
  @ в черновик и открытие проводника телефона. Экран расширений получил явную
  начальную вкладку для перехода из «Плагины».
- ConversationModelSheet заменяет прежний приватный выбор модели в MainScreen.
  Убраны рекламная синяя карточка и API URL; OpenRouter показан нейтральной строкой
  с фактическим известным количеством моделей. Закрытие и заголовок вне прокрутки.
  Среда выполнения выбирается строками с RadioButton-семантикой вместо узкой
  капсулы фиксированной высоты. Подписи переносятся при увеличении шрифта.
- modelPickerOptions сохраняет выбранную модель, отсутствующую в обновившемся
  каталоге, и убирает дубли ID. Сохранённый ID не заменяется другой моделью.

## Границы и следующий проход

- Это адаптация показанного паттерна, не заявление о полном совпадении приложений.
  Для выбора наших провайдеров и места исполнения точного экрана-референса нет.
- Отдельный переключатель «Размышлять глубже» не добавлен: для него необходим
  реальный параметр провайдера и проверка передачи в запрос, а не декоративный UI
  или скрытая замена выбранной модели.
- Фактическая съёмка камерой и выбор фото, импорт содержимого файлов, выполнение
  плагинов с работающим мостом и проверка на физическом телефоне в этот проход
  не входили. Проверка документов использовала отмену системного picker.
- При недоступном мосте экран расширений показывает технический сетевой текст;
  его пользовательское сообщение остаётся отдельным пунктом следующей проверки.
