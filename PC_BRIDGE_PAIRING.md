# Подключение телефона к PC-Bridge

Обновите и перезапустите мост вместе с Android 2.3.0.

1. Запустите PC-Bridge на компьютере. Он покажет шестизначный код. Если мост
   работает скрыто, откройте терминал в проекте и выполните:
   `node pc-bridge/owner-access.cjs pair`.
2. На телефоне откройте Настройки → Подключение к ПК. Укажите адрес этого моста.
   Для интернета нужен HTTPS; HTTP допустим для локального IP в своей сети.
3. В блоке «Сопряжение с телефоном» введите код и нажмите «Сопрячь телефон».
   Код действует 5 минут, допускает не более 5 попыток и используется один раз.

Подключение привязано к точному scheme/host/port. Новый публичный адрес туннеля
требует нового сопряжения. Оно не синхронизируется через GitHub или в другой ПК.
Восстановление Android backup без ключа Android Keystore также требует сопряжения.

Долгоживущий секрет хранится на ПК в `%USERPROFILE%/.antigravity-private/bridge-owner.json`.
Не отправляйте этот файл другим людям и не включайте в репозиторий. На телефоне
секрет зашифрован Android Keystore; в API-параметры моделей и промпты он не входит.

Из локального терминала можно получить однократный URL для браузера:
`node pc-bridge/owner-access.cjs web`. URL действует 30 секунд, после входа удаляется
из адреса, браузер получает HttpOnly cookie на час. Ключ владельца в URL не передаётся.
Встроенная веб-сессия Android получает такой URL сама после сопряжения.

Для собственных CLI-интеграций нужен заголовок `X-Antigravity-Bridge-Token`.
Не выводите его в логи. `/api/health` доступен без него и не раскрывает историю,
рабочую папку, имя компьютера или список сессий. Loopback не обходит авторизацию:
публичные туннели тоже доставляют запросы с loopback.

Если телефон потерян, остановите PC-Bridge, удалите только файл bridge-owner.json
по указанному выше пути и запустите мост заново. Сформируется другой секрет,
все телефоны нужно сопрячь заново. Перезапуск также завершает прежние web-cookie
сессии. Не удаляйте папку с OAuth-ключами MCP и историю чатов.

Для отключения удалённого доступа остановите мост/его туннели. Не отключайте
проверку владельца в коде для обхода ошибки подключения.
